# StickyNotesBoard
In this project, users can create notes, drag and move them anywhere on the board, change note colors, and delete notes.  Building it using HTML, CSS, and basic JavaScript
# 📝 StickyNotesBoard

StickyNotesBoard is a simple and interactive web application that allows users to create, edit, and manage sticky notes. It provides an intuitive interface for organizing ideas, reminders, and daily tasks.

# Features

- ➕ Create new sticky notes
- ✏️ Edit existing notes
- 🗑️ Delete notes
- 💾 Autosave functionality
- 📱 Responsive user interface


## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS
- JavaScript

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/priyaamore/StickyNotesBoard.git
```

2. Navigate to the project directory

```bash
cd StickyNotesBoard
```

3. Install dependencies

```bash
npm install
```

4. Start the server

```bash
node server.js

or
```bash
npm start

5. Open your browser and visit


http://localhost:3000


(Update the port if your application uses a different one.)
